### RULE: JAVA-SEC-201
severity: FATAL
scope: security
intent: 禁止字符串拼接构造 SQL。

detect:
  regex: "SELECT .*\\+|FROM .*\\+|WHERE .*\\+"
  where: filePath in @mainJava/**
fix: 改为参数化查询或 ORM 安全查询方式。
prompt:
  violation: 检测到潜在 SQL 注入风险。
  requirement: 数据库查询必须参数化。
  solution: 使用参数绑定重构查询逻辑。
context:
  - @repository

### RULE: JAVA-SEC-203
severity: WARN
scope: security
intent: 全局异常处理器不得向 API 调用方暴露堆栈或内部实现细节。

detect:
  semantic: global exception handler exposes stack trace details to API callers
fix: 请返回脱敏后的错误响应，并将详细堆栈仅保留在内部日志中。
prompt:
  violation: 检测到异常处理可能泄露内部堆栈或实现细节。
  requirement: 对外错误响应不得包含内部堆栈和敏感诊断信息。
  solution: 请清洗 API 错误响应，仅在日志中保留详细诊断信息。
context:
  - @exception
  - @advice

### RULE: JAVA-SEC-204
severity: WARN
scope: security
intent: 日志中不得记录 password、token、Authorization 头或其他敏感凭据字段。

detect:
  semantic: log statement may include password, token, secret, authorization header, or credential fields
fix: 请在日志前移除或脱敏敏感字段，并统一安全日志工具。
prompt:
  violation: 检测到日志模式可能暴露敏感凭据或秘密信息。
  requirement: 生产日志不得泄露认证材料或敏感凭据。
  solution: 请对敏感字段脱敏，仅记录安全标识或元数据。
context:
  - @service
  - @controller
