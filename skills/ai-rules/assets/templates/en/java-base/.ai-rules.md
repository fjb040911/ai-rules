### RULE: JAVA-SEC-201
severity: FATAL
scope: security
intent: Disallow SQL construction via string concatenation.

detect:
  regex: "SELECT .*\\+|FROM .*\\+|WHERE .*\\+"
  where: filePath in @mainJava/**
fix: Use parameterized queries or safe ORM query APIs.
prompt:
  violation: Detected potential SQL injection risk.
  requirement: Database queries must be parameterized.
  solution: Refactor query logic to use bound parameters.
context:
  - @repository
